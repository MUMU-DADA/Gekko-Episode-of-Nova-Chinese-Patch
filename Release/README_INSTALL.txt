《Gekko Episode of Nova》简体中文汉化补丁

安装方法：
1. 确认这是 Windows 64 位版本，并关闭游戏。
2. 将本压缩包内的全部文件直接解压到游戏根目录。
   游戏根目录应当能看到 Gekko Episode of Nova.exe。
3. 运行游戏即可。BepInEx 会自动加载汉化补丁。

压缩包不会覆盖游戏的 *_Data、UnityPlayer.dll 或其他原始资源。
如果目标目录已有 BepInEx，请允许同名文件覆盖，以使用本补丁附带的运行时组件。

卸载方法：
删除 BepInEx/plugins/GekkoNovaPatch.dll、BepInEx/plugins/GekkoNova_*.tsv，
并删除本补丁附带的 BepInEx 与 Doorstop 文件（或从原始游戏备份恢复）。

注意：本补丁适用于 Unity 2022.3 Mono 版本的游戏。首次启动 BepInEx 可能需要额外等待几秒生成日志目录。
